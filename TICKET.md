# TICKET: Practice AI Application Engineering Interview Questions

## Objective

Use the AI-powered practice agent to identify knowledge gaps and strengthen your understanding of AI application development concepts through interactive quizzing and guided learning.

Read tutorial [AI Application Engineer Interview Prep](https://github.com/easyscale-academy/learn_ai_application_interview-project/tree/01-Prep-AI-Application-Interview/)

---

## Prerequisites

- Claude Code environment with `/practice` skill available
- Basic familiarity with LLM concepts (or willingness to start from Junior level)
- 20-30 minutes per practice session

---

## Tasks

### Task 1: Run Your First Practice Session

**Goal**: Complete one full interview-mode session to establish a baseline.

1. Open Claude Code and type `/practice`
2. Select "Random" to let the agent pick a question
3. Choose "Interview mode" when prompted
4. Answer all 6 questions (3 multiple choice + 3 short answer)
5. Review your score and the feedback summary

**Checkpoint**: You should see a score summary showing areas that need review.

---

### Task 2: Identify Your Weak Topics

**Goal**: Understand which topic areas need the most attention.

Based on your first session:
- Note which questions you got wrong or partially correct
- Look at the topic category (e.g., RAG, Agent Architecture, Prompt Engineering)
- If you scored < 50% on a topic, mark it as a priority

**Checkpoint**: You have a list of 1-3 topics to focus on.

---

### Task 3: Deep Dive with Learning Mode

**Goal**: Build understanding in your weak areas.

1. Run `/practice` again
2. Select "By topic" and choose one of your weak areas
3. This time, select "Learning mode"
4. Ask the agent to explain each concept
5. Use follow-up questions until you understand

**Checkpoint**: You can explain the core concept in your own words.

---

### Task 4: Retest and Measure Progress

**Goal**: Verify that your understanding has improved.

1. Wait at least one day (spaced repetition helps retention)
2. Run `/practice` and select the same topic you studied
3. Choose "Interview mode"
4. Compare your new score to your baseline

**Checkpoint**: Score improved by at least 1-2 questions.

---

### Task 5: Expand Coverage

**Goal**: Ensure broad coverage across all topic areas.

1. Review `questions-index.md` to see all available topics
2. Identify topics you haven't practiced yet
3. Run 2-3 random sessions covering different difficulty levels:
   - Junior (J): Foundation concepts
   - Mid-Level (M): Design and production patterns
   - Senior (S): Architecture and trade-offs

**Checkpoint**: You've attempted at least one question from each major topic area.

---

## Stretch Goals

- [X] Complete all Junior-level questions with 80%+ accuracy
- [X] Identify a Senior-level system design question and work through it in learning mode
- [X] Practice explaining a concept out loud (as if teaching someone else)
- [=] Apply one concept you learned to a real project

---

## Success Criteria

You've completed this ticket when you can:

1. Use `/practice` comfortably in both interview and learning modes
2. Identify your strong and weak topic areas
3. Explain at least 3 core concepts (e.g., RAG pipeline, reranking, prompt injection) without looking at notes
4. Have a study plan for continued improvement

---

## Notes

- Don't rush through questions just to finish — understanding matters more than speed
- If you get stuck on a concept, switch to learning mode immediately
- The goal isn't to memorize answers — it's to build intuition you can apply to new problems
- Consider tracking your scores over time to see progress
