## 什么是 AI 应用工程师？

在 AI 领域，不同角色的工作重心差异很大。理解这些区别能帮助你明确自己的定位和学习方向。

| 角色 | 核心职责 | 典型工作内容 |
|------|---------|-------------|
| **AI 应用工程师** | 构建、部署、运维 AI 驱动的产品 | RAG 系统、Agent 架构、Prompt 工程、API 集成、生产环境优化 |
| **MLE (机器学习工程师)** | 训练、微调、部署模型 | 模型训练 pipeline、特征工程、模型服务化、A/B 测试 |
| **AI Infra 工程师** | 构建支撑 AI 的基础设施 | GPU 集群、分布式训练、模型推理优化、MLOps 平台 |
| **Research Scientist** | 探索新算法、发表论文 | 新模型架构、理论研究、实验验证、学术贡献 |

**本题库专注于 AI 应用工程师**——你不需要从零训练 LLM，但你需要知道如何用好它：

- 如何设计 Prompt 让模型稳定输出结构化数据？
- RAG 系统检索质量差怎么排查？
- Agent 陷入死循环怎么处理？
- 多租户 LLM 平台如何做成本分摊？
- Prompt injection 攻击如何防御？

这些是 AI 应用工程师的日常问题，也是本题库覆盖的核心内容。

## 两种使用方式

### 方式一：AI Agent 引导（强烈推荐）

在支持 Claude Code 的环境中，输入命令：

```
/practice-cn
```

AI Agent 会自动引导你：

1. **选择题目** — 自己指定题号、随机出题、或按主题随机
2. **选择模式** — 面试模式（选择题 + 简答题测试）或学习模式（知识点讲解）
3. **即时反馈** — 每道题都有详细解析和改进建议
4. **成绩总结** — 完成后给出得分和需要复习的领域

**为什么推荐这种方式？**

- 不用自己找题目路径，Agent 自动定位
- 面试模式模拟真实面试，暴露知识盲区
- 学习模式支持追问，按自己节奏深入理解
- 随机出题避免"挑软柿子捏"

### 方式二：自主阅读

如果你更喜欢自己掌控节奏：

1. **浏览题目列表**
   - `questions.md` — 完整大纲，包含所有 100 道题的详细描述
   - `questions-index.md` — 快速索引，按难度和主题组织

2. **找到对应教程**

   每道题都有独立的 README，路径格式：
   ```
   pool/{级别}/{主题}/{题目ID}/README.md
   ```

   例如：
   ```
   pool/01-junior/01-llm-fundamentals/J-01-01-tokens-context-window/README.md
   pool/02-mid-level/02-advanced-rag/M-02-03-reranking/README.md
   pool/03-senior/01-multi-agent-systems/S-01-02-a2a-protocol/README.md
   ```

3. **自己阅读，或丢给任何 AI 帮你解读**

## 练习建议

### 根据经验选择难度

| 你的背景 | 建议起点 |
|---------|---------|
| 刚接触 LLM 应用开发 | 从 J（初级）开始，打好基础 |
| 有 1-2 年经验 | J 快速过一遍，重点刷 M（中级） |
| 有 3+ 年经验 | 直接刷 M 和 S（高级） |
| 准备面试 | 按目标公司职级选择对应难度 |

### 让 AI 评估你的水平

不确定从哪开始？把你的简历或项目经历发给 AI Agent：

```
这是我的背景：[粘贴简历/项目经历]
请推荐适合我的题目难度和主题。
```

### 每次练习 3 道题

- 面试模式：3 道选择题 + 3 道简答题
- 控制在 20-30 分钟
- 做完看反馈，复习薄弱点
- 隔几天再来一轮，巩固记忆

## 导师笔记

> **写给想系统学习 AI 应用开发的你**

这个题库不是为了"背答案过面试"，而是为了帮你建立**系统的知识框架**。

AI 应用开发变化很快——去年的最佳实践今年可能已经过时。但有些东西是不变的：

- **理解原理比记住 API 更重要**。知道 Reranker 为什么有效，比记住 Cohere API 调用方式更有价值。
- **权衡思维比追求"最优解"更重要**。生产环境没有银弹，只有 trade-off。
- **动手实践比看文档更重要**。这个题库只是起点，真正的学习发生在你用这些知识解决实际问题的时候。

**建议的学习路径**：

1. 用 `/practice-cn` 先做一轮随机测试，找到自己的知识盲区
2. 针对薄弱主题，切换到学习模式深入理解
3. 隔一周再测同一主题，检验掌握程度
4. 把学到的东西用到实际项目中

祝学习愉快，面试顺利！
